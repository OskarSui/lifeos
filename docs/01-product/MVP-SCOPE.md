# MVP Scope

## Must have

- Today Dashboard
- Today's Focus
- Quick Capture
- Kanban with INBOX, IN_PROGRESS and DONE
- Task title, description, status, priority and optional due date
- Goal
- Daily Review
- Responsive UI

## Not in MVP

- AI assistant
- Team collaboration
- Notifications
- Integrations
- Recurring tasks
- Files
- Complex analytics
- Native mobile app

# Product Principles

## 1. Action over organization

The product should encourage action, not endless planning.

## 2. One main focus

A day may contain many tasks, but only one task is the main focus.

## 3. Capture first. Organize later.

Quick ideas should be captured without mandatory fields.

## 4. Less noise

Every feature must justify its existence.

## 5. Mobile-friendly from day one

The web application must remain usable on a phone.

## Feature filter

Ask:

> Does this help the user move from intention to action?

If not, it belongs outside the MVP.
